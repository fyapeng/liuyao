# 六爻排盘

现代简约风的六爻起卦排盘网页。纯静态，`index.html` 直接用 GitHub Pages 托管即可。

## 功能

- **三种起卦**：铜钱摇卦（三枚铜钱 3D 翻转动画，摇六次成卦）、时间起卦（梅花易数年月日时）、数字起卦
- **全自动装卦**：纳甲、安世应、六亲、六兽、旬空、变卦
- **断卦提示**：动爻、按问事类别定的用神、日月旺衰表（旺相休囚死）、世应说明
- **规则速查**：起卦法、纳甲歌、安世应诀等折叠查阅，附简化声明

## 规则引擎

`engine.js` 为纯函数规则引擎（无 DOM 依赖），`test.mjs` 为 68 项单元测试：

```bash
node test.mjs   # 68 通过
```

- 64 卦由八宫纯卦按变爻规律程序生成（本宫→一世→…→五世→游魂→归魂），无硬编码卦表
- 纳甲按「乾内甲子外壬午…」歌诀由上下卦推导
- 日柱以 1900-01-01 甲戌日为基准推算；月建默认按节气近似，请按实际手动选择

## 文件

| 文件 | 说明 |

## 部署

推送到 GitHub 仓库后，在 Settings → Pages 选择分支即可通过自定义域名访问。
